# สเปกรูป Rich Menu (เมนูล่างของแชท LINE)

เอกสารนี้ส่งให้คนหรือ AI ที่จะออกแบบรูปใหม่ได้เลย — มีทุกอย่างที่ต้องรู้

เมนูมี **2 หน้า** สลับด้วยแท็บด้านบน — และมีสองทางที่จะได้รูปมา
**ทางที่ 1 ง่ายกว่ามากถ้าใช้ AI วาดรูป**

## ทางที่ 1 (แนะนำ) — ขอแค่ "ไอคอน 1:1" แล้วให้สคริปต์ประกอบ

เครื่องมือ AI วาดรูปส่วนใหญ่เลือกอัตราส่วนได้แค่ชุดสำเร็จ (1:1, 4:3, 16:9, 9:16, …)
ซึ่ง **ไม่มีอันไหนตรง 1.4828 ที่ rich menu ต้องการเลย** — ที่ใกล้สุดคือ 4:3
ซึ่งยังต้องครอปความสูงทิ้ง 10% ส่วน 16:9 ต้องครอปความกว้าง 17%

และอัตราส่วนถูกอย่างเดียวยังไม่พอ — **เส้นแบ่งต้องตรงตาราง 833 px พอดี**
ครอปทีเดียวเส้นเลื่อนทั้งหน้า กดปุ่มแล้วไปโดนช่องข้าง ๆ

**ทางออก: ขอแค่ไอคอน อัตราส่วน 1:1 ทีละอัน รวม 12 อัน** (เป็นอัตราส่วนที่
เครื่องมือพวกนี้ทำได้ดีที่สุดอยู่แล้ว) แล้ววางไว้ที่ `assets/icons/`

```
assets/icons/tab1-1.png … tab1-6.png     ไอคอนหน้า "หลัก"    เรียงตามตารางข้อ 4
assets/icons/tab2-1.png … tab2-6.png     ไอคอนหน้า "เพิ่มเติม"
```

```bash
python3 scripts/richmenu_compose.py      # → richmenu-tab1-custom.png + tab2
```

สคริปต์วางไอคอนลงตาราง เรนเดอร์แถบแท็บกับข้อความไทยให้เอง แล้วบีบให้ไม่เกิน 1 MB

ได้เปรียบกว่าวาดทั้งหน้าเป็นรูปเดียวชัด ๆ:

- **ตารางตรงเป๊ะ 100%** เพราะคำนวณจากตัวเลขชุดเดียวกับ `richmenu.mjs`
- **ข้อความไทยไม่มีทางสะกดเพี้ยน** — AI วาดรูปเขียนไทยพลาดบ่อยมาก
  (เคยเจอ "ถ่ายสลับ" แทน "ถ่ายสลิป" ซึ่งดูด้วยตาแทบแยกไม่ออก)
- แก้ไอคอนทีละอันได้ ไม่ต้องสั่งวาดใหม่ทั้งหน้า
- ขนาดไฟล์คุมให้อัตโนมัติ

**สิ่งที่ต้องบอก AI:** ไอคอนสไตล์ 3D นุ่ม ๆ โทนพาสเทล · **พื้นหลังโปร่งใส (PNG alpha)**
· อัตราส่วน 1:1 · **ไม่ต้องมีตัวหนังสือในรูป**

> ถ้าไอคอนมาพร้อมวงกลมพาสเทลของตัวเองอยู่แล้ว สคริปต์ตรวจเจอและจะไม่วาดวงซ้อนให้อีก

## ทางที่ 2 — วาดทั้งหน้าเองเป็นรูปเดียว

ถ้าออกแบบด้วยเครื่องมือที่กำหนดขนาดเป็นพิกเซลได้เอง (Figma, Photoshop, Canva)
ก็ทำทั้งหน้าตามสเปกข้อ 1–4 ด้านล่างได้ ส่งมา 2 ไฟล์

| ไฟล์ | หน้า |
|---|---|
| `assets/richmenu-tab1-custom.png` | หน้า **หลัก** |
| `assets/richmenu-tab2-custom.png` | หน้า **เพิ่มเติม** |

---

ไม่ว่าทางไหน จบด้วย `node scripts/richmenu.mjs create`

> รูปตัวอย่างที่สคริปต์วาดไว้ให้ดูเป็นแนว: `richmenu-tab1.png` / `richmenu-tab2.png`
> เปิดดูก่อนเริ่มออกแบบจะเห็นภาพเร็วขึ้น

## 1. ข้อกำหนดไฟล์ (บังคับ)

| หัวข้อ | ค่า |
|---|---|
| ขนาด | **2500 × 1686 px** (ห้ามคลาดเคลื่อนแม้แต่พิกเซลเดียว) |
| อัตราส่วนทั้งรูป | **≈ 1.483 : 1** (ทอนแล้ว 1250 : 843 ย่อต่อไม่ได้) |
| นามสกุล | **PNG** หรือ **JPEG** |
| ขนาดไฟล์ | **ไม่เกิน 1 MB ต่อไฟล์** |
| ความโปร่งใส | ไม่ควรใช้ — LINE เรนเดอร์ทับพื้นหลังแชทที่คุมไม่ได้ |

`scripts/richmenu.mjs` ตรวจให้ก่อนอัปโหลด ถ้าไม่ผ่านจะฟ้องและหยุด
ไม่ปล่อยขึ้นไปให้ LINE ตอบ error ที่อ่านไม่รู้เรื่อง

> ⚠️ **อย่าคำนวณความสูงเองจากอัตราส่วน** — 1.483 ไม่ใช่เลขกลม ๆ ถ้าเผลอปัดเป็น 3:2
> จะได้ 2500 × 1667 ซึ่งผิดและถูกปัดตกตอนอัปโหลด **ให้ใส่ 1686 ตรง ๆ**
>
> 💡 **ที่ขนาดนี้ภาพสไตล์ไอคอนสีเป็น PNG จะประมาณ 2 MB คือเกินโควตา**
> ให้ส่งออกเป็น **JPEG คุณภาพ ~95** แทน (ได้ราว 700 KB) การลดจำนวนสีใน PNG
> จะทำให้ไล่เฉดพัง — JPEG คุ้มกว่าสำหรับงานที่มี gradient เยอะ

## 2. เลย์เอาต์ — แถบแท็บ 230px + ตาราง 3 × 2

**เหมือนกันทั้งสองหน้า** ต่างแค่แท็บไหนถูกไฮไลต์ กับเนื้อในช่อง

```
        0            833          1666         2499
      ┌──────────────────────┬──────────────────────┐
    0 │      แท็บ ซ้าย        │      แท็บ ขวา        │  1250 × 230
      │      “หลัก”           │     “เพิ่มเติม”      │
  230 ├─────────────┬────────┴────┬─────────────────┤
      │             │             │                 │
      │   ช่อง 1     │   ช่อง 2     │     ช่อง 3      │  833 × 728
      │             │             │                 │
  958 ├─────────────┼─────────────┼─────────────────┤
      │             │             │                 │
      │   ช่อง 4     │   ช่อง 5     │     ช่อง 6      │  833 × 728
      │             │             │                 │
 1686 └─────────────┴─────────────┴─────────────────┘
```

| พื้นที่ | x | y | กว้าง | สูง |
|---|---|---|---|---|
| แท็บซ้าย | 0 | 0 | 1250 | 230 |
| แท็บขวา | 1250 | 0 | 1250 | 230 |
| ช่อง 1 | 0 | 230 | 833 | 728 |
| ช่อง 2 | 833 | 230 | 833 | 728 |
| ช่อง 3 | 1666 | 230 | 833 | 728 |
| ช่อง 4 | 0 | 958 | 833 | 728 |
| ช่อง 5 | 833 | 958 | 833 | 728 |
| ช่อง 6 | 1666 | 958 | 833 | 728 |

**เส้นแบ่งในรูปต้องตรงกับตารางนี้เป๊ะ ๆ** ไม่งั้นผู้ใช้จะกดโดนช่องข้าง ๆ
ช่องมีอัตราส่วน **≈ 1.14 : 1** (กว้างกว่าสูงเล็กน้อย) เว้นขอบใน ~50 px ทุกด้าน

(3 × 833 = 2499 → คอลัมน์ขวาสุดเหลือขอบ 1 px ที่กดไม่ติด ไม่ต้องกังวล
แค่อย่าวางอะไรสำคัญชิดขอบขวาสุด)

### แท็บต้องบอกให้ได้ว่าตอนนี้อยู่หน้าไหน

หน้า 1 ไฮไลต์แท็บซ้าย · หน้า 2 ไฮไลต์แท็บขวา ใช้ได้หลายวิธีรวมกัน:
พื้นหลังแท็บที่เลือกสว่างกว่า · ตัวอักษรเข้มกว่า · มีขีดสีใต้แท็บ

**กดแท็บที่เปิดอยู่ได้ ไม่พัง** (สลับมาที่เดิม) จึงไม่ต้องทำให้ดูกดไม่ได้

## 4. ข้อความในแต่ละช่อง

บรรทัดบน = ชื่อปุ่ม (ตัวหนา ใหญ่) · บรรทัดล่าง = คำอธิบาย (เล็ก สีจาง)

### หน้า 1 — แท็บ “หลัก”

| ช่อง | ชื่อปุ่ม | คำอธิบาย | กดแล้ว |
|---|---|---|---|
| 1 | ถ่ายสลิป | เปิดกล้อง | เปิดกล้อง |
| 2 | เลือกรูป | จากคลังภาพ | เปิดคลังภาพ |
| 3 | สรุป | ยอดเดือนนี้ | ส่ง `สรุป` |
| 4 | รายการ | ดูและลบ | ส่ง `รายการ` |
| 5 | งบ | ตั้งและเช็ค | ส่ง `งบ` |
| 6 | ช่วยเหลือ | คำสั่งทั้งหมด | ส่ง `ช่วยเหลือ` |

### หน้า 2 — แท็บ “เพิ่มเติม”

| ช่อง | ชื่อปุ่ม | คำอธิบาย | กดแล้ว |
|---|---|---|---|
| 1 | สรุปสัปดาห์ | จันทร์ถึงวันนี้ | ส่ง `สรุปสัปดาห์` |
| 2 | สรุปทั้งหมด | ตั้งแต่เริ่มใช้ | ส่ง `สรุปทั้งหมด` |
| 3 | รายจ่าย | เฉพาะขาออก | ส่ง `รายการรายจ่าย` |
| 4 | ตั้งค่า | เตือนและบัญชี | ส่ง `ตั้งค่า` |
| 5 | ข้อมูลของฉัน | ที่เก็บไว้ | ส่ง `ข้อมูลของฉัน` |
| 6 | ลบข้อมูล | ถามยืนยันก่อน | ส่ง `ลบข้อมูลของฉัน` |

ปรับถ้อยคำได้ แต่ **ความหมายต้องตรงเดิม** เพราะข้อความที่ถูกส่งเมื่อกดถูกฮาร์ดโค้ดไว้

ฟอนต์: **Noto Sans Thai** (หรือฟอนต์ไทยอื่นที่อ่านง่าย) —
ชื่อปุ่มไม่ควรเล็กกว่า ~85 px และคำอธิบาย ~55 px ในรูป 2500 px
เพราะจอจริงย่อลงเหลือราว 1/3

## 5. ตัวสำรอง (fallback)

`richmenu.mjs` เลือกไฟล์ตามลำดับนี้ ต่อหนึ่งหน้า

| หน้า | ลำดับ |
|---|---|
| แท็บ 1 | `richmenu-tab1-custom.png` → `.jpg` → `richmenu-tab1.png` |
| แท็บ 2 | `richmenu-tab2-custom.png` → `.jpg` → `richmenu-tab2.png` |
| หน้าเดียว | `richmenu-custom.png` → `.jpg` → `richmenu.png` |

**เข้าโหมดแท็บก็ต่อเมื่อมีรูปแท็บครบทั้งสองหน้า** ไม่งั้นถอยไปโหมดหน้าเดียว
(3 × 2 เต็มหน้า ช่องละ **833 × 843** ไม่มีแถบแท็บ) — บังคับโหมดได้ด้วย
`create --tabs` / `create --flat`

ต้องครบทั้งคู่ เพราะเลย์เอาต์ของ **หน้าแรก** ก็ต่างกันด้วย ถ้าเข้าโหมดแท็บ
ทั้งที่หน้าแรกยังเป็นรูปแบบเก่า พิกัดปุ่มจะเลื่อนทั้งหน้า

ไฟล์ `richmenu*.png` (ไม่มี `-custom`) สคริปต์ `richmenu_image.py` วาดให้
**อย่าแก้มือ** — รันสคริปต์ใหม่ทับได้ตลอด

> ข้อจำกัดของรูปที่สคริปต์วาด: `NotoSansThai-*.ttf` เป็นฟอนต์ subset เฉพาะไทย
> ไม่มี glyph ASCII **รวมถึงเลข 0-9** และไม่มี emoji เลย ไอคอนทุกตัวจึงต้องวาดด้วยเส้น
> ถ้าออกแบบด้วยเครื่องมือกราฟิกก็ไม่ติดข้อจำกัดนี้แล้ว

## 6. ทดสอบ

```bash
node scripts/richmenu.mjs check     # ตรวจรูปอย่างเดียว ไม่แตะ LINE (ไม่ต้องมี token)
node scripts/richmenu.mjs create    # ตรวจ → ลบของเก่า → อัปโหลด → ตั้ง alias → ตั้ง default
node scripts/richmenu.mjs list      # ดูเมนูกับ alias ที่มีอยู่
```

`check` ใช้ได้โดยไม่ต้องมี `.env` — ส่งให้คนออกแบบรูปตรวจงานตัวเองได้เลย
มันจะพิมพ์พิกัดทุกช่องออกมาให้เทียบกับรูป

ในแอป LINE อาจต้อง **ปิด-เปิดห้องแชทใหม่** ถึงจะเห็นรูปใหม่ (มี cache ฝั่งเครื่อง)

จากนั้นกดให้ครบทุกช่องทั้งสองหน้าแล้วเทียบกับตารางข้อ 4 — ถ้ากดช่องไหนแล้วได้ผลของช่องอื่น
แปลว่าเส้นแบ่งในรูปไม่ตรงตาราง

> การสลับแท็บต้องใช้ **LINE เวอร์ชัน 11.5.0 ขึ้นไป** เครื่องที่เก่ากว่านั้นกดแท็บแล้วจะเงียบ
> (ปุ่มในตารางยังใช้ได้ปกติ)
