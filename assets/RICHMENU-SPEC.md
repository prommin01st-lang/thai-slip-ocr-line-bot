# สเปกรูป Rich Menu (เมนูล่างของแชท LINE)

เอกสารนี้ส่งให้คนหรือ AI ที่จะออกแบบรูปใหม่ได้เลย — มีทุกอย่างที่ต้องรู้

**ผลลัพธ์ที่ต้องการ: ไฟล์รูป 1 ไฟล์** วางไว้ที่ `assets/richmenu-custom.png`
แล้วรัน `node scripts/richmenu.mjs create`

---

## 1. ข้อกำหนดไฟล์ (บังคับ)

| หัวข้อ | ค่า |
|---|---|
| ขนาด | **2500 × 1686 px** (ห้ามคลาดเคลื่อนแม้แต่พิกเซลเดียว) |
| อัตราส่วนทั้งรูป | **≈ 1.483 : 1** (ทอนแล้ว 1250 : 843 ย่อต่อไม่ได้) |
| อัตราส่วนต่อช่อง | **≈ 0.988 : 1** — เกือบจัตุรัส สูงกว่ากว้างนิดเดียว |
| นามสกุล | **PNG** หรือ **JPEG** |
| ขนาดไฟล์ | **ไม่เกิน 1 MB** |
| ความโปร่งใส | ไม่ควรใช้ — LINE จะเรนเดอร์ทับพื้นหลังแชทที่คุมไม่ได้ |
| ชื่อไฟล์ | `richmenu-custom.png` (หรือ `.jpg`) |

`scripts/richmenu.mjs` ตรวจ 3 ข้อแรกให้ก่อนอัปโหลด ถ้าไม่ผ่านจะฟ้องและหยุด
ไม่ปล่อยขึ้นไปให้ LINE ตอบ error ที่อ่านไม่รู้เรื่อง

> 💡 **ที่ขนาด 2500 × 1686 ภาพสไตล์นี้เป็น PNG จะประมาณ 2 MB คือเกินโควตา**
> ให้ส่งออกเป็น **JPEG คุณภาพ ~95** แทน (ได้ราว 700 KB) หรือถ้าจะยืนยันใช้ PNG
> ต้องลดจำนวนสีลง ซึ่งจะทำให้ไล่เฉดพัง — JPEG คุ้มกว่าสำหรับงานที่มี gradient เยอะ

> LINE เองรับกว้าง 800–2500 px และอัตราส่วน ≥ 1.45 แต่ **โปรเจกต์นี้ล็อกที่ 2500 × 1686**
> เพราะพิกัดปุ่มถูกฮาร์ดโค้ดไว้ตามตารางขนาดนี้ (ดูข้อ 2)
>
> ⚠️ อย่าคำนวณความสูงเอาเองจากอัตราส่วน — 1.483 ไม่ใช่เลขกลม ๆ ถ้าเผลอปัดเป็น 3:2
> จะได้ 2500 × 1667 ซึ่งผิดและถูกปัดตกตอนอัปโหลด **ให้ใส่ 1686 ตรง ๆ**

## 2. ตำแหน่งปุ่ม — ตาราง 3 คอลัมน์ × 2 แถว

แต่ละช่องกว้าง **833 px** สูง **843 px** พิกัดวัดจากมุมซ้ายบน (0, 0)

```
        0            833           1666         2499
      ┌─────────────┬─────────────┬─────────────┐
    0 │  ถ่ายสลิป   │  เลือกรูป   │    สรุป     │
      │  (กล้อง)    │ (คลังภาพ)   │ (ยอดเดือนนี้)│
  843 ├─────────────┼─────────────┼─────────────┤
      │   รายการ    │     งบ      │  ช่วยเหลือ  │
      │ (ดู/ลบ/แก้) │ (ตั้งและเช็ค)│(คำสั่งทั้งหมด)│
 1686 └─────────────┴─────────────┴─────────────┘
```

| ช่อง | x | y | กว้าง | สูง | ป้าย | สิ่งที่เกิดขึ้นเมื่อกด |
|---|---|---|---|---|---|
| บน-ซ้าย | 0 | 0 | 833 | 843 | **ถ่ายสลิป** | เปิดกล้อง |
| บน-กลาง | 833 | 0 | 833 | 843 | **เลือกรูป** | เปิดคลังภาพ |
| บน-ขวา | 1666 | 0 | 833 | 843 | **สรุป** | ส่งข้อความ `สรุป` |
| ล่าง-ซ้าย | 0 | 843 | 833 | 843 | **รายการ** | ส่งข้อความ `รายการ` |
| ล่าง-กลาง | 833 | 843 | 833 | 843 | **งบ** | ส่งข้อความ `งบ` |
| ล่าง-ขวา | 1666 | 843 | 833 | 843 | **ช่วยเหลือ** | ส่งข้อความ `ช่วยเหลือ` |

**เส้นแบ่งในรูปต้องอยู่ตรงกับตารางนี้เป๊ะ ๆ** ไม่งั้นผู้ใช้จะกดโดนช่องข้าง ๆ
(3 × 833 = 2499 → คอลัมน์ขวาสุดเหลือขอบ 1 px ที่กดไม่ติด ไม่ต้องกังวล
แค่อย่าวางอะไรสำคัญชิดขอบขวาสุด)

พื้นที่ปลอดภัย: เว้นขอบในแต่ละช่อง **~60 px** ทุกด้าน เพราะบางเครื่องครอปขอบนิดหน่อย

## 3. โทนสีของแอป

| บทบาท | สี |

| ตัวอักษรรอง | `#8A8A8A` |

## 4. ข้อความในแต่ละช่อง

บรรทัดบน = ชื่อปุ่ม (ตัวหนา ใหญ่) · บรรทัดล่าง = คำอธิบาย (เล็ก สีจาง)

| ชื่อปุ่ม | คำอธิบาย |
|---|---|
| ถ่ายสลิป | เปิดกล้อง |
| เลือกรูป | จากคลังภาพ |
| สรุป | ยอดเดือนนี้ |
| รายการ | ดูและลบ |
| งบ | ตั้งและเช็ค |
| ช่วยเหลือ | คำสั่งทั้งหมด |

ปรับถ้อยคำได้ แต่ **ความหมายต้องตรงเดิม** เพราะข้อความที่ถูกส่งเมื่อกดถูกฮาร์ดโค้ดไว้

ฟอนต์: **Noto Sans Thai** (หรือฟอนต์ไทยอื่นที่อ่านง่าย) —
ตัวอักษรไม่ควรเล็กกว่า ~64 px ในรูป 2500 px เพราะจอจริงย่อลงเหลือราว 1/3

## 5. ตัวสำรอง (fallback)

`assets/richmenu.png` เป็นรูปเดิมที่ `scripts/richmenu_image.py` วาดด้วย Pillow
**ยังอยู่เหมือนเดิม ไม่ถูกลบ** — `richmenu.mjs` เลือกไฟล์ตามลำดับนี้

1. `assets/richmenu-custom.png`
2. `assets/richmenu-custom.jpg`
3. `assets/richmenu.png` ← ตัวสำรอง

อยากถอยกลับไปใช้ของเดิม: ลบ `richmenu-custom.*` ทิ้งแล้ว `create` ใหม่ เท่านั้น

> รูปที่วาดจากสคริปต์มีข้อจำกัดที่ทำให้อยากเปลี่ยน: `NotoSansThai-*.ttf` เป็นฟอนต์
> subset เฉพาะไทย ไม่มี glyph ของ `/ ? · |` และไม่มี emoji เลย ไอคอนทุกตัวจึง
> ต้องวาดด้วยเส้นเอง ถ้าออกแบบด้วยเครื่องมือกราฟิกก็ไม่ติดข้อจำกัดนี้แล้ว

---

## 6. ทดสอบ

```bash
node scripts/richmenu.mjs check     # ตรวจรูปอย่างเดียว ไม่แตะ LINE (ไม่ต้องมี token)
node scripts/richmenu.mjs create    # ตรวจรูป → ลบเมนูเก่า → อัปโหลด → ตั้งเป็น default
node scripts/richmenu.mjs list      # ดูว่าขึ้นแล้ว
```

`check` ใช้ได้โดยไม่ต้องมี `.env` — ส่งให้คนออกแบบรูปตรวจงานตัวเองได้เลย

ในแอป LINE อาจต้อง **ปิด-เปิดห้องแชทใหม่** ถึงจะเห็นรูปใหม่ (มี cache ฝั่งเครื่อง)

จากนั้นกดให้ครบทั้ง 6 ช่องแล้วเทียบกับตารางข้อ 2 — ถ้ากดช่องไหนแล้วได้ผลของช่องอื่น
แปลว่าเส้นแบ่งในรูปไม่ตรงตาราง
